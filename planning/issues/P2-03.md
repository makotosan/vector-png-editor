# [P2-03] Implement debounced previews and manual toggle / 遅延プレビューと手動切替

## English

### Purpose
Implement debounced previews and manual toggle for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/extension/src/; packages/extension/webview/` (planned paths).

### Implementation
Validate and update after 300ms idle; discard stale responses; manually switch edited SVG/saved PNG without automatic image diff.

### Dependencies
P2-02,P1-04

### Acceptance criteria
Invalid SVG cannot render unchecked; latest source wins; saved preview remains actual saved raster; no auto toggle.

### Test method
Fake timers, rapid edits, out-of-order workers, unsafe source, saved/edited toggle.

## 日本語

### 目的
確定したvector-png Editor v1.0引き継ぎ仕様に基づき、遅延プレビューと手動切替を行う。

### 対象ファイル
`packages/extension/src/; packages/extension/webview/`（予定パス）。

### 実装内容
入力停止300ms後に検証更新し、古い結果を破棄し、編集SVG／保存PNGを手動切替し、自動画像差分は実装しない。

### 依存Issue
P2-02,P1-04

### 受入条件
不正SVGを未検証描画せず、最新原文が優先し、保存previewは実際の保存rasterで、自動切替しない。

### テスト方法
疑似時計、連続編集、worker結果逆転、危険原文、保存／編集切替を検証する。
