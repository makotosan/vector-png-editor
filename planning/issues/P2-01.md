# [P2-01] Register Custom Editor and open routing / Custom Editor登録と起動分岐

## English

### Purpose
Register Custom Editor and open routing for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/extension/package.json; packages/extension/src/` (planned paths).

### Implementation
Implement Vector PNG: Open in Editor, safe detection and ordinary PNG default-viewer fallback; support new 1024×1024 transparent document.

### Dependencies
P0-04,P1-02

### Acceptance criteria
Detection does not execute SVG; corrupt vector-png gets diagnostic; extension does not hijack all PNGs.

### Test method
Extension-host command tests with ordinary PNG, valid vector-png, malformed keyword and new document.

## 日本語

### 目的
確定したvector-png Editor v1.0引き継ぎ仕様に基づき、Custom Editor登録と起動分岐を行う。

### 対象ファイル
`packages/extension/package.json; packages/extension/src/`（予定パス）。

### 実装内容
指定起動コマンド、安全な判定、通常PNGの標準viewerへの分岐、1024×1024透過新規文書を実装する。

### 依存Issue
P0-04,P1-02

### 受入条件
判定時にSVGを実行せず、破損vector-pngに診断を示し、全PNGの標準表示を奪わない。

### テスト方法
通常PNG、有効vector-png、不正キーワード、新規文書の拡張ホストテスト。
