# [P2-02] Bundle secure Webview and Monaco / 安全なWebviewとMonacoの同梱

## English

### Purpose
Bundle secure Webview and Monaco for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/extension/webview/; packages/extension/media/` (planned paths).

### Implementation
Implement left preview/right SVG editor, XML highlighting/completion/search-replace/diagnostics with local Monaco assets and restrictive CSP.

### Dependencies
P2-01

### Acceptance criteria
No CDN or unchecked SVG DOM insertion; bounded messages; local workers operate under CSP; completion respects safe profile.

### Test method
Offline packaged VSIX test, CSP violations/network checks, hostile SVG and completion/search diagnostics.

## 日本語

### 目的
確定したvector-png Editor v1.0引き継ぎ仕様に基づき、安全なWebviewとMonacoの同梱を行う。

### 対象ファイル
`packages/extension/webview/; packages/extension/media/`（予定パス）。

### 実装内容
左preview／右SVG editor、XML強調・補完・検索置換・診断をローカルMonacoと制限CSPで実装する。

### 依存Issue
P2-01

### 受入条件
CDN・未検証SVGのDOM挿入を禁止し、メッセージを上限制御し、CSP下でlocal workerが動き、補完はsafe profileに従う。

### テスト方法
オフラインVSIX、CSP違反・network検査、危険SVG、補完・検索・診断を検証する。
