# [P0-02] Audit safe-svg-v1 and rendering / safe-svg-v1と描画の監査

## English

### Purpose
Audit safe-svg-v1 and rendering for the finalized vector-png Editor v1.0 handoff.

### Target files
`docs/PHASE0.md; docs/SPEC_COMPATIBILITY.md` (planned paths).

### Implementation
Map all element/attribute/resource restrictions and limits to existing validation; review timeout, fonts, transparency and renderer differences.

### Dependencies
P0-01

### Acceptance criteria
Safety, container validity and exact local RGBA comparison are separate; no external fetching or silent stripping.

### Test method
Test prohibited elements, attributes, references, depth, counts, timeout and transparent output.
