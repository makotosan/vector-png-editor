# [P1-01] Package the shared Python Core / 共通Python Coreのパッケージ化

## English

### Purpose
Package the shared Python Core for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/core/pyproject.toml; packages/core/src/; THIRD_PARTY_NOTICES.md` (planned paths).

### Implementation
Reuse pinned MIT vector-png code with attribution; expose bounded parsing, validation, rendering and atomic publication without normalizing source.

### Dependencies
P0-01,P0-02,P0-03,P0-04

### Acceptance criteria
CLI and extension call one Core; upstream source SHA and licenses recorded; no runtime dependency on branch main.

### Test method
Run adapted upstream regressions and install wheel in clean venv.

## 日本語

### 目的
確定したvector-png Editor v1.0引き継ぎ仕様に基づき、共通Python Coreのパッケージ化を行う。

### 対象ファイル
`packages/core/pyproject.toml; packages/core/src/; THIRD_PARTY_NOTICES.md`（予定パス）。

### 実装内容
固定したMIT vector-pngコードを帰属付きで再利用し、原文を正規化せず、上限制御の解析・検証・描画・atomic公開を公開API化する。

### 依存Issue
P0-01,P0-02,P0-03,P0-04

### 受入条件
CLIと拡張が同じCoreを使い、上流SHAとライセンスを記録し、mainへの実行時依存を避ける。

### テスト方法
上流回帰テストを移植して実行し、クリーンvenvへwheelを導入する。
