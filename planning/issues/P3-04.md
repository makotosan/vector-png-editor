# [P3-04] Release VSIX and pip artifacts from tags / タグからVSIX・pip成果物を配布

## English

### Purpose
Release VSIX and pip artifacts from tags for the finalized vector-png Editor v1.0 handoff.

### Target files
`.github/workflows/release.yml; docs/RELEASE.md` (planned paths).

### Implementation
Build/test versioned VSIX and wheel/sdist from tags; publish GitHub Releases and configured pip index with notices and checksums.

### Dependencies
P3-02,P3-03

### Acceptance criteria
Clean installs pass, tag/package versions agree; no stable release before real-machine acceptance; publication failures reported.

### Test method
Dry-run build, install downloaded artifacts, tag-trigger rehearsal and failed-publication recovery.

## 日本語

### 目的
