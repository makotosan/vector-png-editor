# [P2-06] Protect external change conflicts / 外部変更競合の保護

## English

### Purpose
Protect external change conflicts for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/extension/src/; packages/core/tests/` (planned paths).

### Implementation
Watch disk changes with content/revision tokens; reload clean files; notify and preserve dirty content; avoid lost updates at save.

### Dependencies
P2-05,P1-03

### Acceptance criteria
CLI edits never silently overwrite dirty source; conflict preserves both versions and offers review/Save As.

### Test method
External CLI update while dirty/clean, deletion/rename, self-save events and save race.

## 日本語

### 目的
確定したvector-png Editor v1.0引き継ぎ仕様に基づき、外部変更競合の保護を行う。

### 対象ファイル
`packages/extension/src/; packages/core/tests/`（予定パス）。

### 実装内容
内容・revision tokenで外部変更を監視し、clean文書を再読込し、dirty内容を保護して通知し、保存時の更新消失を防ぐ。

### 依存Issue
P2-05,P1-03

### 受入条件
CLI編集がdirty原文を黙って上書きせず、双方を保持して確認／別名保存を提供する。

### テスト方法
dirty／clean時の外部CLI更新、削除・改名、自分の保存通知、保存競合を検証する。
