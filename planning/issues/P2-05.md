# [P2-05] Synchronize VS Code undo/redo and recovery / VS Code履歴同期と復旧

## English

### Purpose
Synchronize VS Code undo/redo and recovery for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/extension/src/; packages/extension/webview/` (planned paths).

### Implementation
Implement CustomDocumentEditEvent undo/redo as authoritative history with Monaco synchronization; backup/revert/hot-exit restoration.

### Dependencies
P2-04

### Acceptance criteria
No duplicate history entries/feedback loops; restored source exact; dirty/save state and multi-view synchronization correct.

### Test method
Keyboard/menu undo/redo, replace-all, save-undo-redo, reload backup, revert and multiple panels.
