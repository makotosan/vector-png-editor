# [P1-02] Implement inspect/extract/validate and JSON contract / inspect／extract／validateとJSON契約の実装

## English

### Purpose
Implement inspect/extract/validate and JSON contract for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/core/src/; packages/core/tests/; docs/CLI.md` (planned paths).

### Implementation
Implement non-executing inspection, exact byte extraction, safe validation, versioned JSON results and stable exit codes.

### Dependencies
P1-01

### Acceptance criteria
Separate container/profile/preview outcomes; ordinary PNG distinct from corrupt vector-png; BOM and CRLF retained; malformed requests bounded.

### Test method
Golden JSON/exit tests, plain/corrupt/unsafe/mismatch cases and exact byte fixtures.
