# [P1-03] Implement build/verify/rebuild transactions / build／verify／rebuildの保存処理

## English

### Purpose
Implement build/verify/rebuild transactions for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/core/src/; packages/core/tests/; docs/CLI.md` (planned paths).

### Implementation
Generate PNG from unchanged source bytes at IHDR viewport; validate complete output then publish atomically; explicit overwrite and conflict tokens.

### Dependencies
P1-02

### Acceptance criteria
Safe violation, timeout, mismatch or conflict leaves original intact; verify reports engine/version and exactness separately.

### Test method
Roundtrip Unicode/BOM/CRLF, differing renderer raster, cancellation, disk failure and concurrent update.
