# [P1-05] Build and validate pip distributions / pip配布物の作成と検証

## English

### Purpose
Build and validate pip distributions for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/core/pyproject.toml; packages/core/tests/; .github/workflows/` (planned paths).

### Implementation
Produce wheel/sdist with all six commands, license notices and documented install/native setup; keep CLI usable independently.

### Dependencies
P1-03,P1-04

### Acceptance criteria
Clean install exposes inspect/extract/validate/build/verify/rebuild; supported Python/OS versions have evidence.

### Test method
Build sdist/wheel, install outside source tree and perform full roundtrip.
