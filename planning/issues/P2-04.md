# [P2-04] Implement source-preserving save and Save As / 原文保持の保存と別名保存

## English

### Purpose
Implement source-preserving save and Save As for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/extension/src/; packages/core/tests/` (planned paths).

### Implementation
Save through the same Core build path, preserving source formatting/BOM/newlines and viewport; support cancellation and Save As.

### Dependencies
P2-03,P1-03

### Acceptance criteria
Invalid profile blocks save; full validation precedes replacement; failed save retains original and dirty buffer.

### Test method
Actual filesystem save/Save As/cancel/permission/disk-failure and exact extraction tests.

## 日本語

### 目的
確定したvector-png Editor v1.0引き継ぎ仕様に基づき、原文保持の保存と別名保存を行う。

### 対象ファイル
`packages/extension/src/; packages/core/tests/`（予定パス）。

### 実装内容
同じCore build経路で原文の整形・BOM・改行とviewportを保持して保存し、取消と別名保存に対応する。

### 依存Issue
P2-03,P1-03

### 受入条件
profile違反で保存を禁止し、全検証後に置換し、失敗時は元ファイルとdirty bufferを保持する。

### テスト方法
実ファイルの保存・別名・取消・権限・ディスク障害・正確な抽出を検証する。
