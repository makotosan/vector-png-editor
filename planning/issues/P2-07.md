# [P2-07] Manage Python venv lifecycle / 専用Python venvの管理

## English

### Purpose
Manage Python venv lifecycle for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/extension/src/; docs/INSTALL.md` (planned paths).

### Implementation
Find user Python, explain absent Python/native Cairo, create dedicated versioned venv, install locked packages and switch only after health checks.

### Dependencies
P1-04,P1-05,P2-01

### Acceptance criteria
Failed/cancelled update preserves active venv and source; no machine-wide Python mutation; paths with spaces/non-ASCII supported.

### Test method
Missing interpreter, unsupported version, offline install, bad wheel, parallel setup and rollback.

## 日本語

### 目的
確定したvector-png Editor v1.0引き継ぎ仕様に基づき、専用Python venvの管理を行う。

### 対象ファイル
`packages/extension/src/; docs/INSTALL.md`（予定パス）。

### 実装内容
利用者Pythonを検出し、未導入Python／native Cairoを案内し、専用版付きvenvへ固定依存を導入し、健全性検査後に切替える。

### 依存Issue
P1-04,P1-05,P2-01

### 受入条件
失敗・取消で既存venvと原文を保護し、全体Pythonを変更せず、空白・非ASCIIパスに対応する。

### テスト方法
Python不在、未対応版、offline導入、不正wheel、並行setup、rollbackを検証する。
