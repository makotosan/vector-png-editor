# [P3-03] Establish CI and protected PR integration / CIと保護されたPR統合

## English

### Purpose
Establish CI and protected PR integration for the finalized vector-png Editor v1.0 handoff.

### Target files
`.github/workflows/; repository main protection` (planned paths).

### Implementation
Configure OS/Python matrix, schema/core/extension/package checks and required main status; PR-only feature branches.

### Dependencies
P0-04,P1-05

### Acceptance criteria
Named required checks exist and pass; main protection enforced; skipped jobs cannot hide required tests.

### Test method
Deliberately failing PR rejected; green PR eligible; compare workflow evidence with matrix.
