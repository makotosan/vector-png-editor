# [P1-04] Define reproducible environments and bridge / 再現可能な環境とbridgeの定義

## English

### Purpose
Define reproducible environments and bridge for the finalized vector-png Editor v1.0 handoff.

### Target files
`packages/core/; schemas/; docs/CLI.md; requirements.lock` (planned paths).

### Implementation
Finalize request/result schema, IDs, diagnostics, cancellation, worker timeouts, Python/native dependency pins and upgrade rollback.

### Dependencies
P1-02,P0-03

### Acceptance criteria
stdout contains only protocol JSON; logs on stderr; stale result IDs ignored; pin install failure preserves active environment.

### Test method
Schema contract tests, malformed/oversized messages, timeout and failed upgrade.
